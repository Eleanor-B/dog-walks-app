# Dog Walks App

A map-based web application for discovering and managing dog-friendly parks and walking locations. Find parks near you, add your own favorite spots, track amenities (fenced areas, bins, toilets, parking), save favorites, and plan routes.

## Features

- 🗺️ Interactive map with dog-friendly locations
- 👤 User accounts and authentication
- ➕ Add and edit custom places
- ❤️ Save favorite locations
- 📝 Track amenities (fenced areas, bins, toilets, coffee, parking)
- 🧭 Route planning and directions
- 📋 Notes for locations

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Supabase** (authentication & database)
- **Mapbox GL & Leaflet** (mapping)
- **Phosphor Icons**
